# FlowPilot (Frontend)

Offline-first Expo React Native TypeScript app for FlowPilot.

## Run

1. `npm install`
2. `npx expo start`
3. Scan the QR code with Expo Go (Android)

## Notes

- All data is stored locally with AsyncStorage.
- No network calls are made; AI and backend features are stubbed.
- Use the floating + button to brain-dump and save tasks to Inbox.
